# 优惠券传播论文：相关工作、贡献边界与基线选择

日期：2026-09-13。延续 `ccf-a-readiness-2026-09-13.md` 的第一项。

## 当前结论

已核查的直接相关工作与本项目的原生传播模型不同，但不能据此宣布“首次研究优惠券分配”或“现有优化算法均不适用”。本项目更有依据的定位是：对不可复制优惠券的终点去重目标，建立固定行为传播模型及可避免全量单券概率矩阵的反向边际估计方法。

这次查阅了 Tang 2018、Chang 等 2019 的全文模型与目标/算法相关章节；沿 Tang 的引用追溯了 Yang 等 2016；核对了通用随机贪心的官方发表页面，并对 2024–2026 年附近相关关键词做定向补查。没有逐条复核其他论文的全部证明，也没有完成系统性的引文数据库检索，因而不作全球优先性声明。

## 原始来源与直接差异

| 工作与核对位置 | 与本项目的关键区别 | 适用判断 |

| [Yang 等 2016，作者稿与问题定义](https://www.cs.sfu.ca/~jpei/publications/CIM%20SIGMOD16.pdf) | 连续折扣改变成为种子的概率；本文为整数券数。CIM 缩写已有另一含义 | 需引用并区分名称；不把连续折扣算法直接命名为本项目基线 |
| [Mirzasoleiman 等 2015，官方论文页](https://ojs.aaai.org/index.php/AAAI/article/view/9486) | 通用单调次模、基数约束随机贪心，减少函数调用，原始保证为期望意义 | 可适配；评估器的统计误差与计算开销仍须单独处理 |

上述模型差异不构成“无法通过任何辅助图或黑盒 oracle 归约”的证明。尤其当 q 已知时，本项目目标就是可被通用方法优化的次模覆盖函数。应说明专用估计器的作用，而非声称一般优化工具不能使用。

文献版本：Tang 暂按已核实的 arXiv 版本引用，不虚构会议；Chang 使用作者公开的 ICDE 2019 完整版记录；Yang 的页码及 DOI 经[作者所在机构记录](https://scholars.duke.edu/publication/1530708)核对。后续若改为出版社正式版，应核对版本差异。

## 两个直接来自本项目定义的区分例子

以下为本次自行推导，不是摘录他人论文，也不证明所有可能归约均不存在。

### 转发与采纳分离

单券在 a→b→c 上移动，a、b 以概率 1 转发，c 以概率 1 核销。结果为一个采纳用户 c。不能把每个经过的节点都视为获得采纳收益的激活节点。这说明原样套用“沿路激活并计数”的传播评估不正确；若另造零权节点或终点副本，仍需证明整个概率过程和预算约束都保持一致。

### 多券独立不是共享同一次采纳决定

一个孤立节点 a，核销概率为 1/2、丢弃概率为 1/2，容量为 2。向 a 投两张独立券：至少一次核销的概率为 1-(1/2)^2=3/4，期望核销券数为 1。

若错误地给两张券共用一个固定采纳决定，则至少一次核销概率变为 1/2。它说明独立性不能丢失；不说明“只有当前 k 联合 RR 一种正确实现”。

## 为什么不能把“必须使用我们的 RR”作为创新论据

在每个可投放节点 v 上建立 c_v 个可区分投放槽位，记集合 U。对每个槽位独立模拟一张券，得到一个核销终点或空结果；对一个选中槽位集合，计算这些终点的并集大小。

对于固定选中集合，这个随机覆盖值的期望恰好等于 sigma(x)。固定全部模拟结果后，其覆盖函数是单调次模的；多个独立批次的平均仍然是单调次模函数。因此，在容量展开空间上，前向样本覆盖与通用贪心可以构成另一条正确的建模路线。

该构造的全量模拟/存储可能很昂贵，尤其槽位数量大时；有限训练样本上选出的最优经验值也有选择乐观偏差，必须独立评估。这正是专用反向估计方法需要通过实验回答的竞争点，而不是将替代路线判为理论上不可行。

类似地，已有 MC-Greedy 先估计 q，再对估计后的乘积目标执行贪心。其估计目标具有 DR 结构，但估计矩阵不等于真实 q；不能把该参考叫作精确最优解。

## 贡献表述的取舍

| 表述 | 处理 |
|---|---|
| 优惠券分配本身是新问题 | 不采用；该应用已有直接相关研究 |
| 单券守恒、核销终止、固定行为、多券独立及终点去重 | 作为明确模型边界；未完成全面查新前不加“首次” |
| NP-hard、DR 次模及精确贪心比例 | 作为模型结构结果；不将标准次模推论包装为通用算法突破 |
| 当前联合 RR 中必须保持券索引一致 | 保留，有覆盖事件依据 |
| 所有正确估计器都必须采用当前联合 RR 形式 | 删除这种暗示；未证明必要性 |
| 专用反向采样避免显式构建全量 q | 可作为算法机制；是否更有效需质量—时间—内存证据 |
| 近似比例自动覆盖固定经验预算 | 不采用；继续明确样本量前提 |

建议主张：本文研究一种独立、不可复制优惠券的传播与分配模型，目标为不同终端核销用户数。利用目标的 DR 结构，将计算重点放在边际估计上；提出保持券索引一致的条件反向采样，并分别给出充分采样条件下的理论保证及经验预算下的性能评估。

## 基线选择及公平比较的具体决定

| 基线 | 优先级 | 实施与解释 |
|---|---|---|
| 已有 MC-Greedy/q 矩阵参考 | 必须保留 | 保留小图高精度参考，补齐矩阵构造、选择时间与内存；不称精确最优 |
| 前向固定样本覆盖 + Lazy Greedy | 优先补充 | 使用独立槽位终点样本，保持同一经验次模函数；计入预计算成本。若每次边际都重新采样，不可直接沿用旧 CELF 上界 |
| 前向评估器 + Stochastic Greedy | 优先补充 | 先在 c_v=1 主设置比较；重复投放需正确展开槽位或证明等价抽样。不能直接把原论文的精确 oracle 保证移植到噪声评估器 |
| Random、Alpha-Sort、1Hop-Sort、拓扑排序 | 必须保留 | 对低重叠/即时采纳主导情况有诊断价值；分别测量计时 |
| 当前 IC-RIS | 保留为模型失配对照 | 明确它以广播模型选择，再在优惠券模型评估；不把它当作同一目标下最强优化器的替代品 |
| 原生 S3CA、折扣优化器 | 暂不直接加入排行榜 | 原生输出和成本结构不同。若设计适配版本，需公开映射、说明改动且不冒称复现原算法；原模型差异仍应在相关工作解释 |

前向基线与 CIM-RIS 的选择/验证/最终评估随机流分开。最终评估统一使用当前固定行为模拟器。匹配样本数只作一种资源口径，还应报告匹配端到端时间与达到同等质量的成本。所有参数与停止规则先固定，再进行完整比较；保留不利配置。

本轮没有实施或运行这些新增基线；上表是文献与目标适用性核对后的实验设计输入。
