# Table Schema

| Table | Purpose | Rows | Metrics | Data source | Replacement owner |
|---|---|---|---|---|---|
| Exact validation | Compare exact enumeration, forward MC, and RR estimates on tiny graphs | Graph and budget | Spread, absolute error, confidence interval | Real exhaustive/MC logs | Authors |
| Reproducibility settings | Record algorithm and hardware settings | Method or machine | epsilon, delta, LB, T, CPU, RAM, repetitions | Real run metadata | Authors |
| Aggregate quality | Compare CIM-RIS with five baselines in three scenarios | Scenario | Mean relative adoption-spread difference | `experiments/results/validated-v2/validated_summary.csv` | Generated by validated-v2 aggregation |

The submission table uses five independent selection/evaluation runs. MC-Greedy
is available on Netscience only; other baseline columns average 24
graph--budget configurations per scenario.

Every planning table must carry the note: PLANNING DATA - replace before submission.
