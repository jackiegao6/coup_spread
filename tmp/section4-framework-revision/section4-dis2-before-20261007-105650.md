# 反向可达集与 SSR 的构造

正向传播从投放节点出发，追踪一张优惠券最终被哪个用户使用。反向采样则先选定一个目标用户 u，再寻找哪些投放节点能够使优惠券最终在 u 处被使用。这样，一次采样的结果就可以用一个候选投放节点集合表示。

**单券反向可达集。** 固定目标用户 u，针对第 j 张券抽取一次辅助随机传播结果。将其中所有“从该节点投放这张券，最终会由 u 使用”的节点组成集合，记为 R_j(u)。因此，s∈R_j(u) 表示在本次抽样结果中，从 s 投放第 j 张券会使 u 使用该券。

这里的“可达”包含最终在 u 处使用这一要求，仅经过 u 而后在其他节点使用或被废弃的轨迹，不计入成功结果。一个反向集合可以包含多个节点，它们表示不同的候选投放位置；每个候选位置分别对应一条单券轨迹，不表示同一张券在传播中发生复制。

**SSR。** 对于同一个目标用户 u，为 k 张券分别独立生成反向集合，并按券编号组成一个样本组。本稿将这样的样本组称为 SSR，记为

$$
\operatorname{SSR}(u)=\bigl(R_1(u),R_2(u),\ldots,R_k(u)\bigr).
$$

一个 SSR 对应一个目标用户，其中第 j 个集合对应第 j 张券。各集合共享目标用户，但使用独立的随机性，并保留各自的编号。接下来先说明如何生成其中的一个 R_j(u)，再给出完整 SSR 的生成方式。

**单券集合如何生成。** 为表示同一节点的多次到访，将传播状态写成 (v,ℓ)，其中 ℓ 是从投放开始已经完成的转发次数。所有候选投放节点都从第 0 层开始，每次转发进入下一层。例如，s→a→s 表示为 (s,0)→(a,1)→(s,2)，两次到达 s 对应不同状态。反向搜索的不同分支若查询同一个 (s,0)，则复用该状态已经抽出的行为。

沿用每个节点都有正终止概率的条件，记

$$
c_v=p_v^a+p_v^d>0,\qquad
\beta=\min_{v\in V}c_v.
$$

对一个 R_j(u)，先抽取随机终止层 H。若 0<β<1，则

$$
\Pr(H=h)=\beta(1-\beta)^h,\qquad h=0,1,2,\ldots.
$$

本次只处理第 0 至第 H 层；优惠券可以在较早的层使用或废弃，在第 H 层则不再转发。H 没有固定上限，用于确定本次采样需要展开多少层。给定 H 后，各状态分别独立生成随机数 r∈[0,1)，按下表的条件概率选择一个完整行为：

| 行为 | 第 ℓ<H 层 | 第 H 层 |
|---|---|---|
| 在 v 使用 | $\dfrac{p_v^a(c_v-\beta)}{c_v(1-\beta)}$ | $p_v^a/c_v$ |
| 在 v 废弃 | $\dfrac{p_v^d(c_v-\beta)}{c_v(1-\beta)}$ | $p_v^d/c_v$ |
| 转发给邻居 w | $\dfrac{p(v,w)}{1-\beta}$ | $0$ |

其中，p(v,w) 沿用第三节的无条件边转发概率。表中的概率用于已抽定终止层后的辅助生成过程，每次抽样只产生使用、废弃或一个转发邻居。若 β=1，直接令 H=0，只使用最后一列。

随后从第 H 层向第 0 层反推。用 C 记录当前已处理层中，最终会使目标用户 u 使用优惠券的节点，具体过程如下。

1. **初始化最后一层。** 抽取状态 (u,H) 的行为。若 u 使用，令 C={u}；否则令 C 为空集。该层没有转发，其他节点无需加入。

2. **向前处理一层。** 依次取 ℓ=H−1,…,0，建立空集 D。检查 u，以及 C 中所有节点的入邻居。对每个待检查节点 w，在本层只抽取一次 (w,ℓ) 的完整行为：若 w=u 且行为为使用，将 w 加入 D；若行为为转发，且选中的邻居属于 C，也将 w 加入 D。其他情况不加入。

3. **更新并继续。** 令 C=D，继续处理更早一层。同一节点在不同层分别抽样；同一状态被不同分支再次检查时复用已有结果。即使某层的 C 为空，也继续向第 0 层推进，因为更早一层的 u 仍可能使用优惠券。

4. **返回单券集合。** 第 0 层处理完毕后，返回 R_j(u)=C。只有第 0 层对应初始投放位置，不将其他层的节点集合并入输出。若 H=0，初始化结果直接作为输出。

每层都检查目标用户的使用行为，因此该过程同时考虑了“到达 u 后立即使用”以及“先离开 u、之后返回才使用”的情况。实现时可将每层待检查节点去重，或缓存状态行为，使同一状态始终只有一个抽样结果。

**完整 SSR 的生成。** 从 V 中均匀抽取目标用户 u，然后独立运行上述单券过程 k 次，得到 R_1(u),…,R_k(u)。每次运行独立抽取自己的终止层 H_j 和各状态的行为，最后将 u 与这 k 个带编号的集合一起保存。空的反向集合也保留其位置；即使整组为空，也保留该次样本。重复这一过程即可得到多个独立 SSR 样本。

对于固定并编号的投放方案 S={s_1,…,s_k}，令第 j 张券从 s_j 投放。检查 SSR 时，只将 s_j 与对应的 R_j(u) 匹配：只要存在一个 j 满足 s_j∈R_j(u)，就将该组记为命中。即使多张券都命中，同一个 SSR 也只计一次，对应目标用户只计一次激活。各集合的券编号因此需要保留，不能先将它们合并成一个普通节点集合。
